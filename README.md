📝 Stand Blog

«A modern and simple blog platform for publishing, managing, and sharing articles.»

Stand Blog is a web-based blogging platform designed for creating and publishing articles in a clean and organized environment.
The project focuses on making article management simple while providing a modern interface for readers.

---

✨ Features

- 📰 Publish and display articles
- ✍️ Create and manage blog posts
- 📚 Organized article listing
- 🔎 Easy navigation between posts
- 👤 Author information
- 📅 Article publishing dates
- 📱 Responsive design
- 🎨 Clean and modern UI
- ⚡ Fast and lightweight

---

🛠️ Tech Stack

- Backend: Python / Django
- Frontend: HTML5 / CSS3 / JavaScript
- Database: SQLite
- Version Control: Git & GitHub

---

🚀 Installation

1. Clone the repository

git clone https://github.com/navidkmp/Stand-Blog.git
cd stand-blog

2. Create a virtual environment

python -m venv .venv

Activate it:

Windows:

venv\Scripts\activate

Linux / macOS:

source venv/bin/activate

3. Install dependencies

pip install -r requirements.txt

4. Run migrations

python manage.py migrate

5. Start the development server

python manage.py runserver

Then open:

http://127.0.0.1:8000/

---

📝 Creating Articles

Articles can be added and managed through the Django admin panel.

Start the server and visit:

/admin/

You can then create, edit, and manage your blog posts.
